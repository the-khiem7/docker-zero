THE WALL

Docker Desktop is the obvious answer, and the first wall.

You start a job on a Windows laptop and you need Docker. Docker's terms make Docker Desktop a paid subscription for professional use in larger organizations. Whether your company has bought it, or ever will, is rarely something you decide from your desk.

Terms and company sizes change, so check Docker's current terms and ask your legal or procurement team. Nothing here is legal advice.

THE MARATHON

So you go around it. By hand.

Docker Engine is open source and runs happily inside WSL2. It works, and you end up doing it with your hands: install a distro, add Docker's apt repository, enable the service, work around a DNS quirk, create a user, start Portainer, dig the setup token out of a log.

After the setup comes the daily part. WSL stops an idle distro and every container in it, and each check on your containers is another command.

THE CLICK

Docker Zero is that guide, automated, with a GUI on top.

One small Windows tray app. One exe sets up Docker Engine inside a WSL2 distro, puts Portainer CE in front of it as the GUI, and keeps both a click away from the tray. It was built so developers who live in WSL can click instead of type, and reach their containers faster.

Setup

One window sets it up.

A setup window installs an Ubuntu-24.04 WSL2 distro, Docker Engine and Portainer CE on https://localhost:9443, creates the Portainer admin and adds a docker command to your PATH. It takes several minutes, mostly for downloads.

  • Windows 10 or 11 with the WSL Windows feature already enabled. Enabling it needs admin rights, so Docker Zero only detects it. If it is missing, ask your IT team to enable WSL once.
  • Internet access to download the distro, Docker Engine and the Portainer image, and a few GB of free disk space.
  1. Download docker-zero.exe from the latest release. Its SHA-256 is listed too.
  2. Run it. The exe is not code-signed, so Windows SmartScreen may ask you to confirm the first time.
  3. Choose a Portainer admin username and a password of at least 12 characters, then click Start setup.

SAFE BY DESIGN

Everything runs as a standard user.

  • No UAC prompt
  • No Windows service
  • Nothing under Program Files
  • A certificate for localhost only

Portainer uses a certificate created inside the distro for localhost. Until you trust it, the browser shows a warning. Trusting it adds it to the trusted root certificates of your Windows account only, and Windows asks you to confirm. The private key never leaves the distro.

Trusting a certificate is a security decision. This one cannot sign other certificates and is valid only for localhost, 127.0.0.1 and ::1. On a managed device, security tooling may still report a change to the trusted roots.

And it leaves cleanly. Uninstall all removes, in order, an optional backup of the distro to a .tar file you choose, the trusted certificate, the Ubuntu-24.04 distro with every image, container and volume in it, auto start, shortcuts, the docker command and its PATH entry, the .wslconfig line the app added, and the settings. Other WSL distros are not touched.

Questions

Is this Docker Desktop?

No. Docker Zero runs Docker Engine inside a WSL2 distro and uses Portainer CE as the GUI. It does not use or install Docker Desktop.

Do I need admin rights?

Not for Docker Zero. The one exception is switching on the WSL Windows feature, which needs admin rights. Ask your IT team to do that once, and the app does the rest as a standard user.

Is it free?

Docker Zero is under the MIT licence. Docker Engine and Portainer CE keep their own licences, so read them and your company's policy before you rely on them.

Will Windows warn me?

Possibly. The exe is not code-signed, so Windows SmartScreen may ask you to confirm the first time you run it.

Where does everything live?

The distro is in your user profile, under %LOCALAPPDATA%\wsl. The exe, when you turn on auto start or a shortcut, is copied to %LOCALAPPDATA%\Programs\docker-zero. Nothing is written to Program Files or HKLM.

Can I use docker from PowerShell?

Yes. Setup adds a docker command to your PATH. Open a new terminal after setup.

Can I build it myself?

Yes. You need Go 1.26 or newer, Node.js with npm, and the Wails CLI v3.0.0-beta.30.

go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0-beta.30
wails3 task build
